## ✨ 这个网页能做什么?

打开就能用,4 个功能:

🔄 **格式转换**:支持 13 种格式!
SRT / VTT / ASS / SSA / MicroDVD / TTML / SBV / LRC 等等
粘进去自动识别,选目标格式,实时看结果,直接下载 ✓

🔍 **质量校验**
字幕音画不同步?有重叠?时间轴错乱?
自动检测,告诉你第几条字幕有问题 🐛

🧹 **文本规范化**
字幕里一堆 `<i>` `{\b1}` 这种标签看着烦?
一键剥离,只剩纯文字 📝

📊 **字幕信息**
一眼看清楚:什么格式、多少条、总时长、时间戳
拿到陌生字幕先看一眼心里有数 ⏱️
