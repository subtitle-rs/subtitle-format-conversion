## 一个常见但烦人的小需求

你下载了一部电影,字幕是 SRT 格式,但你的播放器只认 VTT。

或者反过来:你用某剪辑软件导出了 ASS 字幕,想传到 YouTube,但 YouTube 只吃 SRT / VTT / SBV。

再或者:你拿到一份 SCC 广播字幕(广播电视用的格式),想看看里面是什么内容。

过去解决这类需求的方式是装一个软件——Subtitle Edit、Aegisub、或者某个名字可疑的「全能格式转换器」安装包。这些软件要么体积大(几十 MB),要么 Windows only,要么要装一堆运行时,要么最后那个还带广告。

**但字幕转换这件事,本质上就是文本处理。为什么非要在本地装一个软件?**

## 我做了个网页版

**核心特点:**

- 🆓 完全免费,无需注册
- 🔒 字幕文件**全程不离开浏览器**,不上传任何服务器
- 📁 支持 13 种格式互转
- 💻 跨平台:Mac / Windows / Linux / 手机浏览器都能用
- ⚡ 即开即用,无需安装

## 支持哪些格式?

```
SRT · VTT · ASS · SSA · MicroDVD · SubViewer ·
TTML · SBV · LRC · SAMI · MPL2 · SCC · EBU STL
```

基本上覆盖了你能在日常生活中遇到的所有字幕格式。从最常用的 SRT/VTT,到剪辑软件的 ASS/SSA,到歌词的 LRC,再到广播电视专业的 SCC/EBU STL。

## 不只是转换:四个工具

打开后你会发现顶部有 4 个 Tab。一份字幕粘进去,4 个角度都能用:

### 1. 格式转换

最常用的功能。粘进去或拖文件,自动识别格式,选目标格式,实时看到转换结果。点「下载」拿到目标格式的文件,或者直接「复制」到剪贴板。

支持把 SRT 转成 VTT 给网页播放器用,把 ASS 转成 SRT 上传 YouTube,把任何格式转成 LRC 当歌词用,等等。

### 2. 质量校验

字幕出了问题(音画不同步、文字闪烁、重叠),自己排查很麻烦。这个工具会自动检测:

- 时间轴重叠(上一条还没结束,下一条就开始了)
- 负时长(开始时间晚于结束时间)
- 时间倒序

有问题会列出来,告诉你具体是第几条字幕。没问题就显示绿色「未发现问题」。

### 3. 文本规范化

很多字幕里带 HTML 或 ASS 样式标签(`<i>斜体</i>`、`{\b1}粗体{\b0}` 这种)。在某些场景下你只想要纯文本(比如做机器翻译的语料、做字幕检索)。

这个工具一键剥离所有标签,保留纯文字内容。可以预览结果、复制、下载。

### 4. 字幕信息

快速看一份字幕的基本情况:格式、总条数、总时长、首末时间戳。拿到的字幕是不是完整的、大概多长,一眼能看出来。

## 「不上传」是怎么做到的?

这点值得单独说一下,因为这是它和绝大多数在线工具的根本区别。

你在网页上粘的字幕,**不会发送到任何服务器**。处理过程全部在你的浏览器里完成,用的是一种叫 **WebAssembly** 的技术——可以理解为浏览器里跑了一段编译好的程序,这个程序直接处理你本机的数据。

好处:

- **隐私**:字幕内容(可能包含你正在看的电影对白、私人翻译)完全在你设备上
- **速度**:没有网络往返,转换是即时的
- **免费**:没有服务器成本,所以可以永久免费
- **离线**:加载过一次后,断网也能用

这也是为什么这个工具可以一直免费放在 GitHub Pages 上——它根本不需要后端。
