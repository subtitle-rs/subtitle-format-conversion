# 多语言支持(i18n)— 设计方案

> 10 种语言(英/俄/法/德/日/越/繁中/简中/阿拉伯/希伯来),含 RTL,预留扩展机制。
>
> 创建时间:2026-10-30
> 基础:v0.3.0(17 格式工具台,main 已上线)

## 1. 需求与决策

- 语言:en, ru, fr, de, ja, vi, zh-TW, zh-CN, ar, he
- 默认语言策略(用户已确认):浏览器语言检测 → 支持则用之,否则**英语兜底**;切换后 localStorage 持久化
- 扩展机制(用户已确认要求「预留」):新语言 = ①`locales/` 加一个 JSON ②`languages.ts` 注册表加一行,零其他改动
- RTL:阿拉伯语、希伯来语需要布局镜像

## 2. 技术选型

**react-i18next + i18next**(React 生态事实标准)。不用 react-intl(ICU 过重)、不自研(复数/检测/回退都是重复造轮子)。体积代价 ~10KB gz。

## 3. 目录结构与扩展机制

```
src/i18n/
├── index.ts            # i18n 初始化:navigator 检测 + localStorage + fallback en
├── languages.ts        # SUPPORTED_LANGUAGES: { code, nativeName, dir }[]
└── locales/
    ├── en.json  zh-CN.json  zh-TW.json  ru.json  fr.json
    ├── de.json  ja.json  vi.json  ar.json  he.json
```

**key 命名空间**(flat 分组):

```
app.title / app.tagline
nav.tools.convert|validate|normalize|repair|info
tool.convert.*  (源格式/目标格式/无法识别/转换结果/复制/已复制/下载/条字幕/输入/上传文件/粘贴文本/拖拽提示/字符/文件较大/输入占位/结果占位/转换失败/引擎加载失败/刷新重试/正在加载)
tool.validate.* (规则集各预设名/条字幕/个问题/未发现问题/校验失败)
tool.normalize.* (标题/选项说明/规范化按钮/点击提示/失败/下载名)
tool.repair.*   (标题/三个操作+参数标签/EDL 区块全部/帧率/切前切后/执行修复/前后条数/结果)
tool.info.*     (标题/五行标签/无法解析)
common.*        (复制/已复制/下载/条字幕/纯本地处理/tooltip)
format.*        (17 个格式显示名)
guideline.*     (basic/netflix/bbc/ted/ard/channel4)
footer.*        (支持格式/隐私说明/基于)
theme.*         (亮色/暗色/跟随系统)
lang.*          (切换语言 label)
```

`FORMAT_LABELS` 从 `lib/formats.ts` 移除,改 `format.*` 翻译键;`FORMAT_EXTENSIONS` 保留(扩展名不是文案)。原 `defaultTarget` 逻辑不变。

## 4. 语言注册表(languages.ts)

```typescript
export interface LanguageDef { code: string; nativeName: string; dir: "ltr" | "rtl"; }
export const SUPPORTED_LANGUAGES: LanguageDef[] = [
  { code: "en",     nativeName: "English",   dir: "ltr" },
  { code: "zh-CN",  nativeName: "简体中文",   dir: "ltr" },
  { code: "zh-TW",  nativeName: "繁體中文",   dir: "ltr" },
  { code: "ja",     nativeName: "日本語",     dir: "ltr" },
  { code: "ru",     nativeName: "Русский",   dir: "ltr" },
  { code: "fr",     nativeName: "Français",  dir: "ltr" },
  { code: "de",     nativeName: "Deutsch",   dir: "ltr" },
  { code: "vi",     nativeName: "Tiếng Việt",dir: "ltr" },
  { code: "ar",     nativeName: "العربية",   dir: "rtl" },
  { code: "he",     nativeName: "עברית",     dir: "rtl" },
];
```

nativeName 用原生语言名(不用当前 UI 语言翻译语言名——国际惯例)。

## 5. 初始化与语言切换

- `main.tsx` 里 `import "@/i18n"` 先于 App 渲染
- i18next 配置:`detection: { order: ["localStorage", "navigator"], caches: ["localStorage"], lookupLocalStorage: "subtitle-converter-lang" }`,`fallbackLng: "en"`,资源静态 import(10 个 JSON 全量打包,~8KB gz,不值得懒加载)
- `LanguageSwitcher`(Header 内,`Languages` 图标 + DropdownMenu,与 ThemeToggle 并排)
- `useDocumentLang()` effect:`document.documentElement.lang = i18n.language; dir = 注册表 dir; document.title = t("app.title")`

## 6. RTL 处理

1. `<html dir>` 随语言切换(见上)
2. 布局:全 flex/grid + Tailwind 逻辑属性,自动镜像;`text-left/right` 尽量不用
3. 图标:`ArrowRight`(FormatPicker 流向)加 `rtl:rotate-180`;其余图标方向中性
4. 字幕内容区(Output/Normalize/Repair 的 `<pre>`、Input 的 textarea)加 `dir="auto"`——按内容首强字符定方向,UI 用希伯来语看英文 SRT 不错乱
5. 数字输入框(`Input type=number`)天然 LTR,不处理
6. 首帧防闪烁:index.html 的内联脚本扩展——除主题外同步读 `subtitle-converter-lang` 设置 `lang`+`dir`

## 7. 翻译产出与范围

- 10 个 JSON 由本次直接产出(UI 短语级,质量足够上线;发布后可由母语者校对)
- **不翻译**:wasm 引擎报错原文(英文)、格式扩展名、代码注释
- 每个语言文件必须包含全部 key(与 en.json 同构);typecheck 阶段用脚本比对 key 集合一致性

## 8. 迁移步骤(每步可验证)

```
1. 装 i18next react-i18next;i18n 基础设施 + en/zh-CN 参照对
2. 逐组件 t() 替换(12 个组件/文件),FORMAT_LABELS 迁移
3. LanguageSwitcher + html lang/dir/title + index.html FOUC 脚本扩展
4. RTL:图标 rtl:rotate-180 + <pre>/textarea dir="auto"
5. 其余 7 语言 JSON + key 一致性校验脚本
6. e2e + build 体积 + 合并 + v0.4.0
```
